# NeuroFlow Designer — Figma Development Plugin

Официальный локальный плагин для Figma Desktop, позволяющий генерировать профессиональные экраны и компоненты дизайн-системы **NeuroFlow** с поддержкой Auto Layout, цветовых переменных и светлой/тёмной тем оформления.

---

## Возможности плагина

1. **Генерация всех 6 экранов NeuroFlow**:
   - **Dashboard**: статус локального узла, метрики, очередь задач, ростер агентов, карточка знаний и журнал событий.
   - **Agents**: мастер-детали каталог агентов, конфигурация модели (Claude, GPT, DeepSeek, Llama), инструменты MCP и разрешения.
   - **Workflows**: граф сценариев со связанными узлами (Trigger, Router, RAG, Approval Gate) и инспектор свойств.
   - **Second Brain**: 3-колоночный интерфейс базы знаний (папки/метки, список документов, ридер со связанными статьями).
   - **MCP Hub**: сетка серверов Model Context Protocol (Filesystem, GitHub, PostgreSQL, Brave, Docker), задержка IPC и список инструментов.
   - **Activity**: сводка расхода токенов моделей и таблица логов аудита.

2. **Настоящие редактируемые элементы Figma**:
   - Не использует растровые скриншоты — генерирует настоящие `FrameNode`, `TextNode`, `RectangleNode` и `EllipseNode`.
   - Все текстовые слои загружаются через `figma.loadFontAsync({ family: "Inter", ... })` и остаются полностью редактируемыми.
   - Все контейнеры используют нативный **Auto Layout** (горизонтальный и вертикальный стек, отступы, паддинги, скругления).

3. **Светлая и тёмная темы (Light & Dark)**:
   - Поддержка фирменной светлой темы `Forest Light` (`#F6F7F4`, белый сурфейс, акцент лайма).
   - Поддержка глубокой инженерной тёмной темы `Obsidian Dark` (`#0E1512`, хвойный уголь `#141E19`, неоновый лайм `#C9ED84`).

4. **Интеллектуальное обновление без дублирования**:
   - При повторной генерации плагин находит существующий фрейм с тем же именем на текущей странице, аккуратно заменяет его содержимое и сохраняет точные координаты холста.

5. **Создание дизайн-токенов в файле**:
   - Кнопка **«Создать цветовые стили»** автоматически генерирует библиотеку локальных стилей Figma Paint Styles (`NeuroFlow/Dark/...`, `NeuroFlow/Light/...`).

## Инструкция по установке и запуску в Figma Desktop

### Шаг 1. Сборка плагина (уже выполнена в репозитории)
Если вы редактировали исходный код TypeScript в папке `src/`, пересоберите плагин:
```bash
cd figma-plugin
pnpm build
```
Сборщик скомпилирует `src/code.ts` в единый чистый файл `dist/code.js`.

### Шаг 2. Открытие Figma Desktop
Запустите приложение **Figma Desktop** (на Windows или macOS) и откройте любой ваш файл (или создайте новый пустой файл).

### Шаг 3. Импорт манифеста плагина
1. Нажмите на логотип Figma в верхнем левом углу (или нажмите `Ctrl+/` / `⌘/`).
2. Перейдите в меню: **Plugins** → **Development** → **Import plugin from manifest...**.
3. В открывшемся окне проводника выберите файл:
   ```
   beautiful-bardeen/figma-plugin/manifest.json
   ```
4. Плагин **NeuroFlow Designer** появится в вашем списке локальных плагинов для разработки.

### Шаг 4. Запуск плагина
1. Кликните правой кнопкой мыши на холсте Figma.
2. Выберите: **Plugins** → **Development** → **NeuroFlow Designer**.
3. Откроется интерфейс плагина:
   - Переключите тему (**Тёмная** или **Светлая**).
   - Выберите экран (например, *⚡ Все 6 экранов* или конкретный экран *Dashboard*).
   - Нажмите **Сгенерировать в Figma**.
4. Плагин загрузит шрифты `Inter`, построит векторные фреймы с Auto Layout и автоматически сфокусирует холст на созданных экранах!
