# DESIGN SYSTEM — NEUROFLOW

## 1. Visual Direction
NeuroFlow — профессиональная self-hosted платформа оркестрации и автоматизации рабочих процессов нового поколения.
Визуальный стиль вдохновлен первоклассными инструментами современной инженерной культуры: **Linear**, **Vercel** и **Raycast**.
- **Dark-first**: глубокая, сфокусированная темная палитра снижает утомляемость при работе со сложными схемами данных.
- **Инженерный минимализм**: тонкие границы (1px), полупрозрачные панели, микроконтрасты, отсутствие декоративного шума.
- **Акцентный цвет**: глубокий электрический фиолетовый (`Neuro Violet`), ассоциирующийся с нейронными связями и интеллектом.
- **Поддержка светлой темы**: чистая, высококонтрастная светлая тема в стиле Vercel / GitHub Next.

---

## 2. Brand Personality
- **Надежность и точность**: каждый узел, ребро и статус отображают реальное состояние системы без визуальных обманов.
- **Технологичность**: чистые линии, моноширинный акцент для данных и JSON, мгновенная тактильная отзывчивость.
- **Тональность**: профессиональная, лаконичная, без лишней разговорности.

---

## 3. Typography
- **Primary Font**: `Inter`, `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Monospace Font**: `JetBrains Mono`, `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace` (для JSON, параметров, ключей, логов)
- **Typographic Scale**:
  - `Text-2xs`: 10px / line-height: 14px (метки портов, технические бейджи)
  - `Text-xs`: 12px / line-height: 16px (подписи узлов, подсказки, метаданные)
  - `Text-sm`: 13px / line-height: 18px (базовый размер текста интерфейса, инпуты)
  - `Text-base`: 14px / line-height: 20px (заголовки карточек, стандартные кнопки)
  - `Text-md`: 16px / line-height: 24px (заголовки секций инспектора)
  - `Text-lg`: 18px / line-height: 28px (заголовки панелей)
  - `Text-xl`: 20px / line-height: 28px (заголовки страниц)
  - `Text-2xl`: 24px / line-height: 32px (главные экраны)

## 5. Spacing & Grid
- Базовый модуль: `4px`
- Шаг сетки редактора: `20px` (точечная сетка `#23273D`)
- Отступы панелей: `p-3` (12px), `p-4` (16px), `p-6` (24px)
- Gap между элементами: `gap-2` (8px), `gap-3` (12px), `gap-4` (16px)

---

## 6. Radius & Borders
- **Borders**: строго `1px solid` с `border-border`
- **Border Radius**:
  - `rounded-sm`: 4px (бейджи статуса, чекбоксы)
  - `rounded-md`: 6px (кнопки, инпуты, теги)
  - `rounded-lg`: 10px (карточки узлов на холсте)
  - `rounded-xl`: 14px (модальные окна, выдвижные панели)

---

## 7. Shadows & Elevation
- **Card Subtle**: `0 1px 3px rgba(0, 0, 0, 0.4), 0 0 0 1px rgba(255, 255, 255, 0.05)`
- **Node Resting**: `0 4px 12px rgba(0, 0, 0, 0.5), 0 0 0 1px rgba(255, 255, 255, 0.07)`
- **Node Selected**: `0 8px 24px rgba(139, 92, 246, 0.25), 0 0 0 2px #8B5CF6`
- **Dropdown / Modal**: `0 16px 36px rgba(0, 0, 0, 0.7), 0 0 0 1px rgba(255, 255, 255, 0.1)`

---

## 8. Node Design Specifications
- Узел на холсте:
  - Минимальная ширина: `260px`
  - Шапка узла: иконка категории + название узла + статус-индикатор + кнопка меню (...)
  - Тело узла: краткое состояние / превью конфигурации
  - Порты подключения: вход (слева, полукруг `8px`), выход (справа, полукруг `8px` или несколько для Condition)
  - Состояние "Running": мягкое неоновое свечение и бегущая анимация по границе.
  - Состояние "Success": деликатная зеленая точка и время выполнения (`42ms`).
  - Состояние "Failed": деликатная красная точка и краткая ошибка.

---

## 9. Motion & Transitions
- Переходы: `150ms cubic-bezier(0.4, 0, 0.2, 1)` для кнопок и ховеров
- Панели (выезд инспектора): `220ms cubic-bezier(0.16, 1, 0.3, 1)`
- Поддержка `@media (prefers-reduced-motion)`: отключение пульсации и мгновенное открытие.

---

## 10. Anti-Patterns
- Никаких кислотных радужных градиентов на фоне.
- Никаких толстых мультяшных границ (2px+ везде).
- Никаких неизменяемых огромных теней.
- Никаких фальшивых спиннеров без реального состояния.
- Никакого неструктурированного дампа ошибок.
