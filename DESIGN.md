# DESIGN SYSTEM — NEUROFLOW STUDIO

## 1. Продуктовое и визуальное видение (Product & Visual Direction)

**NeuroFlow** — персональная self-hosted платформа оркестрации и управления AI-агентами, сценариями автоматизации, локальной базой знаний (Second Brain) и расширениями протокола MCP (Model Context Protocol).

Система спроектирована для **одного владельца** и решает задачи локального суверенитета данных, полного контроля за правами агентов и наблюдаемости процессов.

### Ключевые ориентиры:
- **Refined Minimalism & Quiet Infrastructure**: интерфейс инструмента, а не маркетинговой витрины.
- **Linear**: предельная информационная плотность, безупречный вертикальный ритм, строгая иерархия данных.
- **Raycast**: мгновенная доступность командной палитры (`Cmd+K`), клавиатурная навигация, тактильность.
- **Vercel**: минималистичная типографика, чистый микроконтраст границ, выверенные интерактивные состояния.
- **Modern Developer IDEs**: функциональные рабочие панели, наглядные статусы выполнения, подробные логи и инспекторы свойств.

### Строгие антипаттерны (Anti-Patterns):
- Запрещён "AI-slop" (никаких абстрактных 3D-сфер, размытых фиолетовых "космических" клякс и кислотных градиентов).
- Никакого псевдо-стекла (glassmorphism), мешающего чтению текста.
- Никаких эмодзи в качестве системных иконок (только строгие векторные SVG 16–20px).
- Никаких выдуманных маркетинговых графиков и пустых гигантских карточек.

## 3. Типографика (Typography Scale)

- **Основная гарнитура**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Моноширинная гарнитура**: `JetBrains Mono, ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace` (для JSON, параметров, логов, адресов MCP)

### Шкала размеров:
1. `Label-Caps` (10px / line-height: 14px / font-weight: 700 / letter-spacing: 0.12em / text-transform: uppercase) — надзаголовки (eyebrow), категории секций.
2. `Text-2xs` (11px / line-height: 15px / font-weight: 500) — метаданные, бейджи, подсказки хоткеев.
3. `Text-xs` (12px / line-height: 16px / font-weight: 500–600) — компактные кнопки, подписи полей ввода, статус-бары.
4. `Text-sm` (13px / line-height: 18px / font-weight: 400–600) — базовый размер текста интерфейса, строки таблиц, инпуты.
5. `Text-base` (14px / line-height: 20px / font-weight: 600) — заголовки списков, карточки агентов.
6. `Text-md` (15px / line-height: 22px / font-weight: 650) — заголовки панелей, имя выбранного узла.
7. `Text-lg` (18px / line-height: 24px / font-weight: 650) — заголовки акцентных блоков.
8. `Text-xl` (22px / line-height: 28px / font-weight: 700) — заголовки модальных диалогов.
9. `Text-2xl` (27px / line-height: 32px / font-weight: 700) — числовые метрики дашборда.
10. `Text-3xl` (33px / line-height: 40px / font-weight: 700) — заголовок страницы H1.

## 4. Сетка, отступы и радиусы (Layout, Spacing & Elevation)

### Модульная сетка:
- Базовый шаг: **8px** (микро-шаг **4px**).
- Шкала отступов: `4px` (`space-1`), `8px` (`space-2`), `12px` (`space-3`), `16px` (`space-4`), `20px` (`space-5`), `24px` (`space-6`), `32px` (`space-8`), `48px` (`space-12`).
- Ширина сайдбара: `248px` (десктоп), `72px` (планшет 768–980px), компактный нижний dock (мобильные <680px).
- Высота топбара: `64px`–`72px`.

### Радиусы скругления:
- `radius-sm`: `5px` — чекбоксы, маленькие бейджи, теги.
- `radius-md`: `7px` — инпуты, стандартные кнопки, строки выбора.
- `radius-lg`: `10px` — панели, карточки дашборда, узлы на канвасе сценариев.
- `radius-xl`: `12px` — диалоги командной палитры и модальные окна.

### Границы и тени:
- Строго `1px solid var(--border-default)`.
- Тень для панелей: `0 8px 30px rgba(23, 36, 29, 0.04)`.
- Тень для диалогов: `0 18px 80px rgba(16, 32, 25, 0.28)`.

## 5. Каталог переиспользуемых компонентов

1. **Button**:
   - `Primary`: акцентная заливка, максимальный контраст.
   - `Secondary`: контурная кнопка с тонкой рамкой `var(--border-default)`.
   - `Ghost`: прозрачный фон, акцент при наведении.
   - `Danger`: предупреждающее действие (удаление, отключение сервера).
2. **IconButton**: квадратные кнопки 34x34px с центрированной векторной иконкой.
3. **NavigationItem**: кнопка сайдбара с иконкой 17px, меткой раздела, счетчиком и индикатором активности (полоска лайма).
4. **Tabs**: сегментированный переключатель фильтрации с плавным фокусом.
5. **Badge**: компактный статус-элемент со скруглённой плашкой и цветовой точкой (Success, Warn, Error, Neutral).
6. **StatusIndicator**: живой индикатор доступности узла (онлайн, в работе, спящий режим).
7. **AgentRow / AgentMiniCard**: карточка агента с аватаром-монограммой, ролью, моделью и статусом готовности.
8. **TaskRow**: табличная строка задачи с индексом `01`, наименованием, исполнителем, временем и бейджем статуса.
9. **Input**: поле ввода высотой 38–42px с понятным плейсхолдером и рамкой фокуса.
10. **SearchField**: поисковый инпут с иконкой лупы и бейджем хоткея `Ctrl K` / `/`.
11. **Dialog / CommandPalette**: модальное центрированное окно с затемнением фона, поддержкой клавиатурных стрелок и Esc.
12. **Dropdown / Select**: выпадающее контекстное меню с выбором модели ИИ, уровня логирования или действия.
13. **InspectorPanel**: детальная боковая панель с метаданными, конфигурацией узла и журналами.
14. **EmptyState**: минималистичное состояние отсутствия данных с понятной подсказкой.

## 6. Спецификация 6 экранов системы

### 1. Dashboard (Обзор системы)
- **Статус локального узла**: состояние ядра, активные демоны, задержка IPC, статус готовности.
- **Метрики**: задачи в очереди, доступные агенты, предупреждения, размер базы знаний.
- **Очередь задач**: таблица задач с фильтрами («Все», «В работе», «Ожидают», «Завершены») и добавлением новой задачи.
- **Ростер агентов**: быстрый просмотр команды (Operator, Research, Developer, Architect) с переходом в детали.
- **Лента событий**: хроника активности в реальном времени.

### 2. Agents (Управление агентами)
- Мастер-детали каталог агентов.
- Специализация, текущее состояние («Готов», «Выполняет задачу», «Ожидает»).
- Выбор модели (Claude 3.5 Sonnet, GPT-4o, DeepSeek-R1 Local, Llama 3.3 70B).
- Политика доступа и разрешённые инструменты (чтение, запись, подтверждение опасных команд).
- История недавних выполнений агента с затраченным временем и статусом.

### 3. Workflows (Редактор сценариев)
- Визуальный канвас со связанными узлами: Trigger (Новая задача) -> Router (Operator) -> Memory (Second Brain) -> Condition -> Execution (Developer) -> Gate (Проверка).
- Кликабельные узлы с отображением свойств в правой панели инспектора.
- Переключение вкладок «Свойства узла» и «Лог выполнения» со списком шагов и таймингов.
- Кнопки быстрого запуска теста и сохранения.

### 4. Second Brain (Локальная база знаний)
- 3-колоночная организация: папки/метки -> список документов с поиском -> ридер предпросмотра.
- Полнотекстовый поиск с фильтрацией по тегам `#architecture`, `#agents`, `#mcp`, `#notes`.
- Детальный просмотр статьи со связанными знаниями и источниками контекста.

### 5. MCP Hub (Интеграция Model Context Protocol)
- Список серверов: Filesystem, GitHub, PostgreSQL, Brave Search, Docker Engine.
- Интерактивный Health Check: опрос сервера с расчетом задержки (ping ms) и обновлением статуса в реальном времени.
- Детали инструментов сервера с типами разрешений (Безопасный / Требует подтверждения).

### 6. Activity (Журнал событий и логи)
- Полная история всех вызовов и системных событий.
- Фильтры по уровням: Info, Success, Warning, Error.
- Аналитика расхода токенов по агентам и моделям (Prompt / Completion / Cost / Cache hit).
- Просмотр детального лога с JSON-контекстом и трейсом ошибки.
